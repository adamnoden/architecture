# RH-C3 — bounded service view

RH-C3 compiles only the already-coordinated RH-06 / RH-07 / RH-10 service relationships.

Machine-checked scope:

- semantic service-network connectivity;
- declared host-space geography;
- plant / riser / terminal identity;
- required working, replacement, isolation and inspection access declarations;
- registered building-boundary crossings;
- explicit linkage of vertical service trunks to the RH-C2 `PEN-SV-01` structural interruption;
- protection of principal-room geography from primary infrastructure;
- selected versus fallback crossing state.

Explicitly external:

- pipe, duct and cable sizing;
- pressure loss, airflow and fan duty;
- heat loss and emitter sizing;
- electrical design;
- drainage gradients / invert levels;
- acoustic performance;
- fire stopping and compartmentation adequacy;
- commissioning / balancing;
- product compliance;
- exact branch coordinates where the architectural source does not control them.

The deterministic SVG projection is intentionally non-spatial. It shows semantic connectivity and crossing ownership rather than inventing MEP routing geometry.
