# Architecture

A design project for long-life residential architecture conceived as an **architectural platform**: permanent structure and architecture supporting serviceable, replaceable and adaptable systems.

## Documents

- [House Design Doctrine](docs/house-design-doctrine.md) — the governing design principles, system strategies, review tests, preferred implementations and open design work.

## Status

The doctrine is a design framework, not a site-specific construction specification. Site-specific plans, engineering, calculations, product selections and technical details should be developed separately while remaining consistent with the doctrine.
