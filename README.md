# Long-Life House

An architectural design-research project exploring how a domestic building can remain **architecturally permanent while allowing shorter-lived systems to be maintained, repaired, replaced and adapted without consuming the permanent fabric**.

The project began as a detailed internal `House Design Doctrine`. That document is now treated as the **source corpus**. The active work is the development of a profession-facing illustrated monograph/design guide, a controlled pattern catalogue, a reference-house study and a separate architect-facing implementation brief.

> **Working thesis:** Change should be given deliberate places to occur so that architecture can afford to remain permanent elsewhere.

## Working rule

Do **not** edit the v7 source doctrine into the future publication. It is evidence of the project's thinking and a traceability source.

New work should proceed through:

**Doctrine → Strategy → Pattern → Reference implementation**

with evidence, proportionality, boundary consequences, verification and unresolved research recorded explicitly.

## Current state

The intellectual/editorial framework is advanced. The next major phase is architectural production and validation: conceptual figures, completion of the strongest pattern families, then a reference-house options appraisal and technical/professional red-team.

This repository is now the canonical working home for the project.
