# Reference House

One coordinated worked interpretation of the doctrine. Its purpose is to force architectural and technical propositions to meet one another in a plausible house and expose conflicts that isolated principles or patterns can hide.

It is a test vehicle, not proof.

Start with the [Tectonic Architectural Language](tectonic-architectural-language.md), then the [Vertical Bay Options](vertical-bay-options.md), [Vertical Bay Coordination](vertical-bay-coordination.md) and [External Access & Maintenance Plan](external-access-maintenance-plan.md).

## Whole-house coordination

The Reference House now has a deliberately provisional house-scale fixture:

- [Whole-House Coordination Fixture 01](whole-house-coordination-fixture.md) — two-storey courtyard geometry used to make plan/service relationships explicit without pretending the design is final;
- [Whole-House Coordination Fixture drawing](whole-house-coordination-fixture.svg) — schematic ground/upper plans;
- [Service Topology Coordination](service-topology-coordination.md) — the coordination brief that defined the Phase-5 test;
- [Service Topology Run 01](service-topology-run-01.md) — completed demand / utility / plant / vertical / horizontal / crossing / water-failure sequence with initial pattern occurrences.

That sequence supplied enough genuine conflicts and rewinds for the pattern-language overhaul to pass Phase 5. The Reference House therefore no longer blocks the **corpus audit**, but it remains architecturally and technically provisional.

Next house work should challenge the provisional footprint and room/circulation geometry, coordinate structure and building physics, resolve passive-first environmental design against real openings/orientation, and integrate physical prototype results as they arrive.
