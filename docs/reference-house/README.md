# Reference House

One coordinated worked interpretation of the doctrine. Its purpose is to force architectural and technical propositions to meet one another in a plausible house and expose conflicts that isolated principles or patterns can hide.

It is a test vehicle, not proof. Start with the [Tectonic Architectural Language](tectonic-architectural-language.md), then the [Vertical Bay Options](vertical-bay-options.md) and [Vertical Bay Coordination](vertical-bay-coordination.md).
