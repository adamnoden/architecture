## Control rules

1. A prototype exists to make rejection cheap. Failure is not a reason to weaken the acceptance criterion.
2. The Reference House must remain architecturally complete if W2 and selective floor access both fail.
3. No prototype pass promotes a Reference House expression into universal House Kernel doctrine.
4. No general House Kernel evidence result forces the Reference House to use an implementation that fails G-01 fit or domestic room quality.
5. Conventional controls are real competitors, not straw men.
6. A special interface must buy more than the technical ability to say it is removable.

## RH-10 handoff

The whole-house audit should treat unresolved prototype rows as **bounded dependencies**, not hidden clashes. A dependency becomes a material RH-10 failure only where the virtual house cannot remain coherent if the prototype rejects the experimental implementation.
