# G-01 Danson — D5/D6 Web-Evidence Pack v0.2

**Case:** G01-DAN  
**Status:** source-qualified web pass; D5/D6 not complete  
**Purpose:** harden the Danson dimensional and coupling evidence using publicly inspectable material and distinguish direct fabric evidence from compositional inference.

## 1. Why Danson matters to D5/D6

Danson is currently the richest case for showing that a coherent Georgian house is not generated by one ratio or by a simple `plan → elevation → structure` sequence.

The public conservation record exposes:

- several different principal-room proportion families;
- a shared principal-floor height;
- canted rooms/elevations;
- blind windows used for exterior order;
- blind-window centring that follows interior geometry rather than exterior symmetry;
- floor structure coordinated with window-jamb positions;
- an original principal-room circulation circuit later changed by a shortcut.

Those are unusually useful because several come from fabric investigation rather than retrospective stylistic description.

## 4. D5 — construction dimensions are not automatically grammar dimensions

The fabric report exposes many precise construction values. Examples publicly indexed from the report include:

- Library principal floor beam: **320 × 320 mm**;
- Library principal joists: **335 × 75 mm**;
- Library common joists: **215 × 65 mm**;
- Library ceiling joists: **75 × 70 mm**;
- Saloon fireplace opening: **1500 mm wide × 1480 mm high × 430 mm deep**;
- ground-level rusticated ashlar module: approximately **303 × 660 mm (12 × 26 in)**.

These are valuable evidence but must not automatically enter G-01 architectural grammar.

They can play three different roles:

1. **construction evidence** — how the actual building was made;
2. **coupling evidence** — whether structure or material module responded to architectural geometry;
3. **grammar evidence** — only if a cross-case architectural relationship survives and is deliberately normative.

The Library beam is mainly category 2. The ashlar size is currently category 1. Neither becomes a style rule because it is measurable.

## 5. D5 — stronger conclusion about sectional datum

Danson gives an unusually clean distinction:

```text
PLAN
Entrance Hall   ≈ 4:3
Library         = 2:1
Dining          = 2:1
Saloon          ≈ 1:1 principal axes / canted

SECTION
all principal rooms = 16 ft height
```

The floor therefore achieves unity through a **shared sectional datum while preserving several plan families**.

This strengthens the D5 proposition that a grammar may contain:

- dimensional families by role;
- shared storey/ceiling datums;
- hierarchy across rooms;

without requiring one repeated plan ratio.

## 6. D6 — original principal-room topology is directly documented

The fabric report describes the principal floor as a compact circuit around an elliptical top-lit primary stair, with a secondary/service stair immediately west of it.

The four principal rooms are:

- Entrance Hall — north;
- Dining Room — east;
- Saloon — south;
- Library — west.

The report states that the Saloon originally had access from the Dining Room and Library; the east-of-stair passage was a closet and did **not** originally provide the later direct Hall/Saloon shortcut.

This gives D6 more than adjacency. It gives a documented **sequence condition altered by a later graph edit**.

Record:

### DAN-CPL-00 — principal circuit / later shortcut

- **scope_owner:** DWELLING;
- **attribute:** route / sequence;
- **original condition:** Hall connects into principal-room circuit without direct Hall→Saloon bypass;
- **later condition:** direct shortcut exists;
- **direction:** plan/topology fact rather than elevation coupling;
- **confidence:** high;
- **grammar use:** mutation/calibration case for `connectivity ≠ sequence`.

This is one of the best natural historical mutations in the corpus because the building itself supplies before/after topology.

## 7. D6 — blind-window existence versus blind-window centreline

This remains the strongest direct evidence for **attribute-specific coupling**.

The fabric research records blind windows at Danson. It also records a more unusual fact: in relevant conditions the blind windows are **centred internally**, which puts them out of line with the centre of the external elevation. The report contrasts this with equivalent blind windows in other Robert Taylor villas where the openings are centred on the exterior wall face.

Therefore one object can simultaneously have:

```text
existence_coupling   = ELEVATION_LEADS
centreline_coupling  = PLAN_LEADS
result                = CONTROLLED EXTERIOR COMPROMISE
```

This is not an inference from looking at a façade. It is direct building/fabric interpretation.

### DAN-CPL-02 — blind-window existence

- **scope_owner:** DWELLING / ELEVATION;
- **attribute:** existence;
- **spatial opening function:** absent;
- **façade representation:** present;
- **direction:** ELEVATION_LEADS;
- **confidence:** high.

### DAN-CPL-03 — blind-window centreline

- **scope_owner:** ROOM / DWELLING;
- **attribute:** centreline;
- **interior relation:** internally centred;
- **exterior consequence:** not centred on exterior elevation;
- **direction:** PLAN_LEADS → CONFLICT/COMPROMISE;
- **confidence:** high.

A grammar model with one generic property such as `opening.aligned = true` cannot represent this honestly.

## 8. D6 — structure/opening coupling is direct, not merely visual

The fabric report records the Library floor frame in detail. Most importantly for D6, the main north–south beam is described as spanning **between the jambs of the windows in the north and south walls**.

Record:

### DAN-CPL-04 — Library jamb / floor-frame coupling

- **scope_owner:** ROOM / COMPONENT;
- **subject:** DAN-P-LIBRARY;
- **architectural variable:** north/south window-jamb geometry;
- **structural variable:** principal floor-beam support/alignment;
- **beam:** approximately 320 × 320 mm;
- **direction:** CONSTRUCTION-COORDINATED / MUTUAL at the shared geometry;
- **confidence:** high direct fabric evidence.

This is important because it demonstrates a genuine shared variable:

```text
WINDOW / JAMB POSITION
       ├── belongs to elevation/opening composition
       ├── belongs to room geometry
       └── participates directly in structural floor framing
```

The compiler should not infer structural adequacy from the grammar. But the semantic model should be able to recognise that one coordinate participates in both architectural and structural obligations.

## 9. D6 — canted bays are plan/elevation co-geometry

The house has canted principal bays associated with the Library, Dining Room and Saloon conditions. Fabric research describes the room geometry and exterior geometry together rather than as a façade appliqué.

Record:

### DAN-CPL-01 — canted room / exterior bay

- **scope_owner:** ROOM / DWELLING;
- **attribute:** projection / room form;
- **plan:** principal room incorporates canted geometry;
- **elevation:** corresponding external bay;
- **direction:** MUTUAL;
- **confidence:** high at broad geometric level.

This is a cleaner example of plan/elevation co-evolution than a centred rectangular window.

## 10. D6 — section coordinates differing plans

### DAN-CPL-05 — common principal-floor datum

- **scope_owner:** STOREY / DWELLING;
- **attribute:** room height / storey hierarchy;
- **plan:** several different room geometries and aspect ratios;
- **section:** common 16 ft principal-room height;
- **architectural consequence:** principal floor reads as one hierarchical level despite plan variation;
- **direction:** SECTIONAL DATUM COORDINATES MULTIPLE PLAN FAMILIES;
- **confidence:** high.

This reinforces Marble Hill’s sectional lesson in a different form:

- Marble Hill uses exceptional height to privilege one room;
- Danson uses common height to unify several differently shaped principal rooms.

A vertical grammar therefore needs both **exception** and **shared datum**.

## 11. D6 — historical design image versus executed building

The conservation research notes discrepancies between Malton’s published plan/view and fabric evidence and suggests Malton may have been working from architect’s drawings rather than recording the executed building exactly.

This independently reinforces the Marble Hill source rule:

> historical design/publication geometry and executed fabric are separate evidence classes.

The grammar research should retain both because the difference itself can reveal design negotiation.

## 12. Mutation programme sharpened by direct evidence

### DAN-M01 — restore/bypass the principal sequence

Use the historically documented original and later Hall/Saloon relationship rather than inventing an arbitrary mutation.

Compare:

- original principal-room circuit;
- later direct shortcut.

Evaluate separately:

- route efficiency;
- ceremonial/principal sequence;
- room centrality;
- privacy/control;
- whether G-01 should treat the sequence as invariant, preference or case-specific condition.

### DAN-M02 — exterior-perfect blind-window regularisation

Move the relevant blind-window centreline to an exterior-perfect position while preserving its simulated existence.

Ask:

- which internal condition is lost?
- does the façade gain enough coherence to justify the plan damage?
- is the historical compromise evidence against a hard centring rule?

### DAN-M03 — force one room ratio

Normalize Entrance Hall, Library, Dining and Saloon toward one ratio while holding the principal-floor envelope and common 16 ft height as far as possible.

This is intentionally expected to expose the weakness of ratio monism rather than prove one historical number.

These are now source-defined mutations, but graphical execution/evaluation remains open.

## 13. Current D5 verdict

**Strong enough to reject a universal ratio; not strong enough to promote positive dimensional bands.**

What remains:

- source IDs/phase tags attached to every existing raw room number;
- more opening/bay dimensions where the public report supports them;
- cross-case comparison with Marble Hill and Bedford Square using the same metric fields;
- hold-out testing before any positive proportional preference.

## 14. Current D6 verdict

Danson already supports three high-confidence modelling conclusions:

1. **coupling authority belongs to an attribute, not an object;**
2. **controlled plan/elevation disagreement can be legitimate architecture;**
3. **architectural coordinates can be shared with structural obligations without the grammar becoming structural proof.**

The new Bedford Square work adds a fourth at repository level:

4. **every coupling also needs architectural scope/owner.**

No Georgian-specific hard rule is promoted merely from these modelling corrections.
