# Architectural Grammar

Architectural grammar is the project layer that makes a **selected architectural language** explicit without promoting that language into Ovid’s House doctrine.

The grammar layer may describe topology, hierarchy, ordering, dimensions and proportions, plan/section/elevation relationships, element families and tectonic rules. It remains independent from the computational supported domain: a computational model may represent or check selected grammar relationships, but it does not own the architectural language being represented.

The first active grammar research instance, **G-01**, is now closed at **M4 — Internally validated / controlled** for its bounded v0.1 scope. G-01 is deliberately specific; its rules do not become Ovid’s House doctrine merely because the Reference House uses them.

The largest retained limitation is explicit: v0.1's positive specificity is stronger at architectural body/elevation/threshold scale than in Georgian-specific internal plan grammar. That is research debt, not permission to invent weak plan rules merely for completeness.
