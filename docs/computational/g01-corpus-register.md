# G-01 Corpus and Source-Quality Register — v0.1

**Status:** D1/D2 complete v0.1; D3 semantic trial complete v0.1; source acquisition continues for D4/D5/D6  
**Purpose:** define the first evidence corpus for deriving G-01 and record what each source can legitimately support before any architectural rules are locked.  
**Related:** [G-01 Research Brief](g01-research-brief.md), [Architectural Grammar and Proportion](architectural-grammar-and-proportion.md)

> **Do not derive a rule from a building merely because the building is famous. Derive only what the available evidence can actually support.**

## 1. Why this register exists

G-01 is intended to become a Georgian-derived architectural grammar for contemporary low-rise English houses.

That creates an obvious danger: a small number of familiar buildings, remembered approximately, could harden into a rule system that merely formalises taste.

This register is the control against that.

It records:

- why each source is in the corpus;
- whether it is normative theory, built evidence, ordinary practice or later reinterpretation;
- what level of documentary evidence is currently available;
- what architectural questions it can answer;
- what it **cannot yet** prove;
- whether it belongs to derivation, annotation trial, validation or contextual control.

The corpus should become more rigorous as source material is retrieved.

## 2. Evidence-quality scale

The grades below describe **fitness for grammar research**, not architectural merit.

### P — primary normative source

Original treatise, pattern book or rules text.

Useful for establishing:

- intended rules;
- explicit proportional systems;
- element families;
- what contemporary authors believed could be codified and transmitted.

It is not direct evidence that ordinary buildings consistently followed those rules.

### A1 — measured / primary geometric evidence

Reliable measured drawings, original drawings with scale/dimensions, or equivalent high-quality survey material.

Suitable for:

- metric extraction;
- plan/elevation alignment;
- room ratios;
- bay geometry;
- section relationships.

### A2 — authoritative analytical reconstruction

Detailed conservation or scholarly study with plans/reconstruction drawings and strong fabric/documentary research.

Usually suitable for architectural analysis; exact dimensions must still be checked against the source drawing.

### B — authoritative descriptive evidence

High-quality listing, monograph or archival record describing plan, bays, storeys, hierarchy or construction, but without enough verified metric drawing material currently in hand.

Suitable for:

- corpus selection;
- topological hypotheses;
- qualitative counterexamples.

Not yet suitable for precise ratio extraction.

### C — contextual control

Architecturally useful comparison but unsuitable as a primary rule-extraction case because of:

- exceptional scale;
- major later alteration;
- different typology;
- later reinterpretation;
- incomplete evidence.

### X — not ready

Interesting candidate with insufficient evidence to enter analysis.

## 3. Analysis roles

Each case also receives a methodological role.

**TRIAL** — one of the first cases to annotate end-to-end.  
**DERIVE** — may contribute to candidate-rule extraction.  
**HOLD-OUT** — deliberately withheld from initial rule extraction; later used to test generalisation.  
**CONTEXT** — informs boundaries, lineage or counterexamples but does not determine the grammar.  
**THEORY** — normative/historical source.  
**MUTATION** — controlled negative case derived from a strong precedent.

This split should be established **before** measurements are analysed and should not be casually changed because a result is inconvenient.

### Normative-corpus rule

Do not count repeated publication of the same idea as independent built evidence.

The theoretical corpus answers:

> **What rules were articulated?**

The built corpus answers:

> **What relationships actually persisted in architecture?**

Those questions must remain separate.

### Urban-corpus rule

Do not allow narrow plots, party walls and London fire/building controls to become freestanding-villa invariants.

Instead ask:

> which relationships survive despite a radically different site morphology?

Those are candidates for the deeper grammar.

## 9. Initial derivation / validation split

The split below is provisional but should not be changed merely because later results are inconvenient.

### First annotation trials

These are chosen to stress different aspects of the model.

#### T1 — Marble Hill House

Tests:

- compact English Palladian villa;
- strong measured evidence;
- plan/elevation/section coordination;
- canonical but not enormous.

#### T2 — Danson House

Tests:

- later Georgian development;
- compact sophisticated planning;
- rich conservation/reconstruction evidence;
- proportion + structure together.

#### T3 — 76 Dean Street

Tests:

- urban constraint;
- double-pile planning;
- storey hierarchy;
- façade/occupation relationship.

The point of T3 is not to make townhouse rules universal.

It tests whether the annotation schema survives a radically different domestic morphology.

### Initial hold-out cases

Do **not** use these to tune the first candidate rules unless the research programme explicitly records a change.

- **Kings Nympton Park** — particularly valuable because it is historically described as closely following Marble Hill. If a grammar derived partly from Marble Hill cannot recognise Kings Nympton without special pleading, something is wrong.
- **2 New Street, Leicester** — ordinary-scale urban control.
- **29 Storey’s Way** — twentieth-century adaptation.
- **Tiverton House** — contemporary adaptation.

### Context controls

Keep outside the core fitting process:

- Chiswick House;
- Houghton Hall;
- Basildon Park;
- Wrotham Park;
- Ridgehanger;
- Davey’s Farm.

These can expose scope boundaries without distorting the main language.

## 11. Metric extraction rules

When measurement begins:

1. record the source drawing identifier;
2. record whether the drawing is original, measured, reconstructed or schematic;
3. preserve raw dimensions;
4. preserve units;
5. record drawing scale;
6. flag inferred dimensions separately;
7. never average conflicting sources silently;
8. distinguish structural wall line from clear room dimensions;
9. distinguish original condition from later alteration;
10. record uncertainty.

Derived ratios are downstream data.

The raw measurement remains authoritative.

## 12. Topology can begin before metric retrieval

Some useful analysis does not require dimensions.

Where reliable plans or plan descriptions exist, we can already annotate:

- room roles;
- adjacency;
- circulation depth;
- entrance relationship;
- public/private/service hierarchy;
- enfilade;
- stair position;
- garden/courtyard relationship.

This means G-01 research does not need to wait for perfect metric evidence before learning from topology.

But topological evidence must not be misrepresented as dimensional evidence.

## 13. Social-history annotation

Historical domestic topology cannot be separated entirely from occupation.

For each case, record where evidence permits:

- owner/household type;
- servants/service arrangements;
- entertaining floor;
- gendered/private/public use where documented;
- later changes caused by changing domestic life;
- colonial/slavery-linked wealth where directly relevant to the house's commission or material culture.

This is not a moral footnote detached from the grammar.

It may explain why a spatial relationship exists.

The normative G-01 decision can then consciously:

- preserve;
- transform;
- or reject that relationship.

For example, a service route created by a servant hierarchy should not become a twenty-first-century invariant merely because it appears repeatedly in the corpus.

## 14. Mutation corpus plan

Do not select existing buildings as “bad Georgian” merely to manufacture contrast.

The first negative corpus should be controlled.

For Marble Hill and Danson create mutations such as:

- M01 — shift one principal opening off both bay and room axis;
- M02 — enlarge a secondary room until hierarchy reverses;
- M03 — break one primary wall alignment;
- M04 — displace stair relative to main ordering structure;
- M05 — vary one façade bay width;
- M06 — equalise upper/lower opening hierarchy;
- M07 — remove an important enfilade connection;
- M08 — insert unnecessary circulation;
- M09 — alter room aspect ratio while preserving area;
- M10 — move principal entrance away from the dominant ordering relationship.

Each mutation changes **one named relationship at a time** where possible.

This is architectural controlled experimentation.

## 15. What this corpus may and may not prove

The corpus can eventually support claims such as:

- certain topological structures recur;
- certain dimensional bands recur;
- certain forms of hierarchy are stable across scale;
- certain plan/elevation alignments are characteristic;
- some theoretical ratios are common or uncommon in actual examples;
- some mutations destroy recognisable coherence faster than others.

It cannot by itself prove:

- universal beauty;
- universal Georgian practice;
- a scientifically objective aesthetic;
- that every future house should use G-01;
- that historical social arrangements should survive.

The source-pack pass has already forced four useful model refinements:

- symmetry must be represented with explicit domain/scope rather than a single building-level boolean;
- architectural observations must carry historical-phase provenance because a geometrically authoritative drawing may represent a later state;
- plan/elevation coupling needs directional states rather than a generic “aligned” flag;
- deliberate absence/closure (for example a blind window or protected solid field) must be representable as architectural data.
