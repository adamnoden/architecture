The complete bounded-house paper compile and final red team are complete.

## 2. Capability-state vocabulary

### DEMONSTRATED INTERNALLY

The paper programme has exercised the capability across representative scales/mutations.

### RESEARCH-SUPPORTED + EXTERNAL PROOF

The topology/family is bounded enough for H1 research, but technical adequacy depends on competent external evidence.

### CANDIDATE / PARTIAL

Useful semantics or obligations exist, but a complete bounded family/proof route has not been hardened.

### EXTERNAL

Permitted/required but deliberately outside current compiler proof competence.

### FUTURE PHYSICAL

Can only be proved by construction, inspection, testing or commissioning.

### UNSUPPORTED

Intentionally outside H1.

## 23. Hard alarms for the implementation phase

Change course if prototype work shows:

1. most important obligations collapse into generic external evidence;
2. one-source semantics cannot survive executable geometry;
3. source well-formedness requires an effectively general CAD/BIM kernel before useful compiler logic exists;
4. selective invalidation becomes too opaque/expensive;
5. family extensions require schema rewrites rather than composition;
6. authoring requires expert metadata comparable to conventional BIM bureaucracy;
7. external rule/evidence provenance cannot be kept legible/versioned;
8. solver-generated “resolvable” hints are presented as validity;
9. architectural quality is reduced to arbitrary numeric constraints;
10. compiler convenience starts driving house design.

These are project-level stop signals.

## 24. Final pre-implementation decision

The internal paper phase is complete enough.

Do not add another paper scale.

The project has earned exactly two next moves:

1. **competent external attack** on structure, regulation/fire and building services; and
2. **the smallest executable semantic/compiler prototype** that can reproduce the core H1/S1 mechanisms with simple geometry.

Everything heavier must be earned by those tests.
