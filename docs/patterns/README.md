# Patterns

This area holds reusable architectural responses developed from the doctrine.

House Systems Architecture now uses an evidence-qualified **pattern language**: stable pattern identities, sparse typed relationships and generative sequences that help designers combine recurring architectural responses without confusing them with strategies, implementation families or compiler rules.

Phase 7 is the active migration phase. **P7A has created canonical individual pages for every surviving pre-audit pattern identity and has retired `HSA-P-006` explicitly.** The old [Core Pattern Catalogue](core-12.md) remains temporarily intact as migration provenance until the later cleanup checkpoint; it is no longer the preferred reading surface for P-001–P-012.
