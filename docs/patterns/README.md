# Patterns

This area holds reusable architectural responses developed from the doctrine.

The project is evolving from a **pattern catalogue** to an evidence-qualified **pattern language**: stable pattern identities, sparse typed relationships and generative sequences that help decide when and in what order patterns should be applied.

The migration has passed both its worked Reference House gate and the complete **Phase-6 corpus audit**. A controlled Phase-7 canonical migration is now authorised. Until that migration lands, the [Core Pattern Catalogue](core-12.md) remains the developed source for most existing pattern prose; do not mistake its old grouping for the final taxonomy.

Phase-6 classification is controlled by:

- [Phase 6 Gate Review](../development/pattern-language-phase6-review.md) — canonical migration set, held candidates, strategies and migration order;
- [Phase 6 Corpus Audit](../development/pattern-language-corpus-audit.md) — detailed classification rationale;
- [Targeted Evidence Review](../research/pattern-language-phase6-targeted-evidence.md) — evidence used to resolve ambiguous classifications.
