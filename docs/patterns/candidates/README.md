# Held Pattern Candidates

These propositions are useful and serious, but **not canonical Ovid’s House patterns**.

They have no `HSA-P-*` identity and are excluded from the canonical pattern index until their stated admission gate is crossed. A candidate may have good precedent and still remain held because the unresolved question is architectural transfer, domestic proportionality or physical quality.

Current held candidates:

- [Replaceable Architectural Lining](replaceable-architectural-lining.md)
- [Individually Isolatable Manifold Distribution](individually-isolatable-manifold-distribution.md)
- [Local Deep Service Zone](local-deep-service-zone.md)
- [Selective Floor Access](selective-floor-access.md)

Candidates are not promoted because the publication needs a complete-looking list. Promotion requires a stronger recurring invariant, sufficient evidence and/or the physical/worked proof specified on the candidate page.
