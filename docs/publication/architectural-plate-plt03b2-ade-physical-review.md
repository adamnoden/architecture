## Finished-PDF font defect and correction

The first finished-PDF gate rejected Liberation fallback. Both the shared
ADE-03B token and ADE-07 embedded-face declaration used the unquoted family
`Source Sans 3`; the standalone number makes that CSS family invalid. The
font bytes were present and correctly pinned, but the browser could not use
them through those declarations. Earlier SVG-only font claims therefore did
not establish rendered Source Sans identity.

Quote the family in those two owning declarations. Regenerate all six ADE-07
plan/contrast outputs and both ADE-06 atlas outputs. Before updating their
fingerprints, reverse only that exact quotation in memory and require every
result to reproduce the previous accepted hash. This proved that no geometry,
label, layout, line/tint metric or semantic ledger changed. The new exact-font
outputs require renewed rendered inspection; the finished-PDF gate is the
regression that prevents another byte-presence-only acceptance.

The historical ADE-04A/04B/05B isolated token fixtures are not current PLT
candidates and remain historical evidence. This packet fixes the active
shared atlas/migration path; it makes no new font-acceptance claim for them.

## Review key

- White band: represented cavity between masonry leaves; no insulation product or technical specification selected.
- Quiet physical partitions: provisional dry-framed family, represented at 125 mm; no door selected.
- External span: approximate or ranged aperture; aperture subtraction follows ADE's precision rule.
- Diamond: opening centre known, width unknown; no invented aperture.
- Faint host band: occurrence without chosen position.
- Offset bracket: required connectivity without a chosen door.

These marks expose unresolved facts. They are not missing finished-drawing
symbols to be replaced by plausible construction details.

## Physical verdict required

Print **B5 page 2** and **the A2 page** at **Actual size / 100%**. Use the
baseline page only for comparison. Inspect:

1. Across room (A2): plan massing, placement and white space.
2. Reading distance: architecture before labels; quiet but legible wall layers,
   room order, partitions, uncertainty and dimensions.
3. Close scrutiny: continuous outer/courtyard joins, white cavity, inner-leaf
   distinction, aperture subtraction, partition abutments and the review key.

uncertainty/adjacency grammar, BOOK composition and WALL composition. A plain

qualifications; do not invent observations beyond that verdict.
