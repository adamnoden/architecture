# Editorial

Controls for how the project is written rather than what it claims architecturally.

The [Editorial Doctrine](editorial-doctrine.md) is the canonical guide to prose modes, rhythm, compression and rewrite discipline. It remains at v0.3 while EDA-00 audits and hardens it; no draft EDA rule supersedes the canonical doctrine until that gate closes.

The [EDA — Editorial Doctrine Audit](eda-programme.md) is the active post-migration editorial assurance programme. It audits the audit standard first, then proves the current reader-facing corpus against the hardened doctrine at sentence, paragraph, page and whole-book scale. EDA close is required before PR-02 private physical-object production.

[EDA-00](eda-00-doctrine-audit.md) records the current doctrine audit and the bounded hardening required for v0.4.

The [Editorial Overhaul Plan](editorial-overhaul-plan.md) is retained as the historical execution record for the completed repo-wide prose migration. Its phase order and branch instructions are provenance, not the current editorial work queue.
