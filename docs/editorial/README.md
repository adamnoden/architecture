# Editorial

Controls for how the project is written rather than what it claims architecturally.

The [Editorial Doctrine](editorial-doctrine.md) is the canonical guide to prose modes, rhythm, compression, rhetorical scale, page-level emphasis and rewrite discipline. **v0.4 is the frozen EDA audit standard.**

The [EDA — Editorial Doctrine Audit](eda-programme.md) is the active post-migration editorial assurance programme. It audits the current reader-facing corpus against the hardened doctrine at sentence, paragraph, page and whole-book scale. EDA close is required before PR-02 private physical-object production.

[EDA-00](eda-00-doctrine-audit.md) is closed. It records why v0.3 was retained and surgically hardened rather than replaced, the v0.4 changes, and the self-audit that froze the new standard. **EDA-01 — corpus and prose-mode register — is next.**

The [Editorial Overhaul Plan](editorial-overhaul-plan.md) is retained as the historical execution record for the completed repo-wide prose migration. Its phase order and branch instructions are provenance, not the current editorial work queue.
