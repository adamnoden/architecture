# Development

This directory contains **internal integration and programme-control material**: documents used to move an architectural proposition from idea toward coordinated publication, testing or delivery.

Typical contents include:

- integration and migration plans;
- coordination registers;
- manufacturing or implementation strategy;
- prototype programmes and test planning;
- working architectural notes whose purpose is to drive changes elsewhere.

It does **not** contain the prototype artefacts themselves. Build packs, test details, drawings and later test records belong in [`../prototypes/`](../prototypes/).

It is also not the canonical public doctrine. When development work settles an architectural position, that result should be absorbed into the appropriate manuscript, pattern, reference-house or delivery document and linked back here where provenance matters.

See [`../README.md`](../README.md) for the repository-wide documentation model.
