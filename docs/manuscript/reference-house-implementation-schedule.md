# Appendix C — Reference House Implementation Schedule

The Reference House is coordinated at virtual-design scope. It is not a construction package.

This schedule marks the boundary between the architectural work already completed and the project work that would be required before the house could responsibly move toward construction on a real site.

It is not a promise that every current Reference House choice will survive. A real project is expected to change the house.

## Status key

**Controlled** — sufficiently resolved to act as the current architectural baseline at virtual scope.

**Professional gate** — requires competent specialist design or review before the assumption can be treated as project fact.

**Physical gate** — requires prototype, first article, test or construction evidence.

**Site gate** — cannot be resolved honestly without a real site.

**Reopen trigger** — a finding that should return the project to an earlier architectural decision rather than being patched downstream.

## Decision sequence on a real project

A real commission should not begin by detailing the current Reference House.

The first task is to recover the relationships that are meant to survive translation:

1. confirm client brief, life-course needs and longevity ambition;
2. establish site, planning, environmental and utility facts;
3. test whether courtyard morphology remains justified;
4. select the architectural grammar and principal spatial order;
5. establish structure, maintenance geography and current/future environmental strategy together;
6. freeze major service/plant routes only after the architecture can carry them proportionately;
7. engineer and simulate before multiplying non-standard details;
8. prototype only the high-consequence/non-standard interfaces whose claims require physical proof;
9. procure without losing interface ownership or turning stewardship into bureaucracy;
10. commission performance plus selected consequential maintainability claims;
11. hand over records that improve future care without becoming the only thing making the building intelligible.

The Reference House provides a starting hypothesis for that sequence, not a template to copy.
