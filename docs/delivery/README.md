# Delivery

Delivery translates sufficiently mature Ovid’s House propositions into requirements for a real commission without pretending that research material is already construction information.

The [RIBA Implementation Brief Template](riba-implementation-brief-template.md) shows how doctrine, selected patterns, project-specific architecture, evidence boundaries and unresolved specialist work can enter an architect-led project through ordinary stage decisions and responsibilities.

More specific requirements remain separate where they need to be issued or tested independently. [External Maintenance Access Requirements](external-maintenance-access-requirements.md), for example, turns maintenance geography into explicit site, route, working-space and replacement-access obligations without prescribing one permanent access system. [Human-Factors Verification Requirements](human-factors-verification-requirements.md) turns low-friction-inhabitation findings into complete-action, finished-interface and stage-specific proof obligations while explicitly refusing unnecessary prototype work.

The governing distinction is simple: **delivery material states what a project must resolve; it does not convert an unresolved research proposition into proof.**
