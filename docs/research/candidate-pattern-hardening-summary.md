# Candidate Pattern Hardening — Decision Matrix

**Status:** post-evidence-review checkpoint  
**Purpose:** state what the first hardening pass actually changed, what is currently preferred, and what must happen before any candidate becomes a reference-house requirement.

## Overall result

None of the four candidates has been disproved.

More importantly, none should now be pursued in its original naive form.

The hardening work has converted each from a slogan into a constrained design problem:

| Candidate | What survives | What is rejected | Current direction | Next gate |
|---|---|---|---|---|
| Seated Floor Structure | Separate support from restraint; explicit load paths; bounded movement | “Let the joists float”; custom sliding bearing by default | Certified restraint hanger as baseline; compare direct bearing and only then custom seat | Structural-engineer option study + 1:1 edge |
| Architectural Backplane | Few deliberate permanent anchors; reusable attachment plane | Universal technical rack on every wall | Sparse, selective, non-proprietary backplane on walls that need fixing/services/panels | Load classes + wall-bay prototype |
| Replaceable Wall Lining | Room surface can be independent of masonry and repeatedly removable | Whole-house cassette wall; panelisation for its own sake | Dense masonry as real wall/boundary; robust manufactured panels on room side | Full principal-room wall bay vs plaster benchmark |
| Finish-Agnostic Floor Platform | Common platform can carry different finish-specific carriers | Commercial raised-access floor copied into a house | Low-profile dense mineral platform; local deeper service zones; access-band comparator | Walkable multi-finish acoustic prototype |

## Strategic consequence

The project is converging on **hybrid construction**, not maximum demountability.

The slow architecture remains heavy, continuous and conventional where those qualities are valuable.

The fast architecture becomes dry, manufactured and reversible only where change is plausible enough to justify it.

That produces a clearer hierarchy:

```text
PERMANENT / CONTINUOUS
masonry • structure • major boundaries
             │
             ▼
SPARSE INTERFACE INFRASTRUCTURE
bearings • backplanes • frames • service routes
             │
             ▼
REPLACEABLE ARCHITECTURAL ASSEMBLIES
wall panels • floor platforms • joinery • trims
             │
             ▼
COMMODITY / WEARING COMPONENTS
sockets • valves • fans • controls • appliances
```

The project should resist adding reversibility above or below the point where it buys real value.

# 1. Seated Floor Structure

## Current conclusion

The intellectual proposition is stronger than the bespoke-detail proposition.

Approved Document A and ordinary restraint hardware already validate the key idea that gravity support and wall restraint can be understood separately.

The current baseline should therefore be ordinary certified hardware.

### Preferred option order

1. **Certified restraint-type masonry hanger**
2. **Direct/seated bearing with separate restraint**
3. **Custom steel ledge/shoe only if it demonstrates a specific advantage**
4. Timber ledger / wall plate as low-priority comparator

## Kill condition

Reject the custom seat if it:

- adds more permanent masonry anchors;
- increases fire/acoustic edge complexity;
- does not make inspection or repair materially easier;
- exists mainly to make the detail philosophically “purer”.

## Key principle retained

> **Make gravity support explicit; provide restraint deliberately; do not create movement freedom without a demonstrated purpose.**

---

# 2. Architectural Backplane

## Current conclusion

The backplane remains one of the strongest project ideas, but only as **selective infrastructure**.

Its value is greatest where several future demands overlap:

- repeat fixing;
- removable wall lining;
- electrical/data distribution;
- substantial joinery;
- known future adaptation.

A low-service masonry wall may not need one.

## Preferred characteristics

- sparse permanent anchors;
- simple steel/timber/aluminium geometry;
- standard screws/bolts;
- adjustable for masonry tolerance;
- load-classified;
- non-proprietary/remanufacturable;
- hidden in ordinary architecture.

## Kill condition

Reject or simplify it if:

- occupants routinely bypass it because it is inconvenient;
- it consumes large wall depth for little benefit;
- it creates acoustic/fire flanking;
- it depends on a proprietary clip family;
- ordinary plaster + a few designed fixing points would be better.

## Key principle retained

> **Penetrate the permanent wall deliberately once; let ordinary future attachment happen on the room side of that interface.**

# 3. Replaceable Wall Lining

## Current conclusion

The best wall is currently a **hybrid**, not a cassette.

For principal masonry rooms:

```text
dense masonry / real boundary
          │
optional permanent parge / air layer
          │
sparse adjustable backplane
          │
shallow service / absorption zone where useful
          │
robust manufactured lining panel
          │
room
```

The panel should not be the only thing making the wall structurally, acoustically or environmentally credible.

## Wall types

### W1 — real plaster/mineral wall

Default where access/fixing burden is low.

### W2 — backplane + removable mineral panel

Candidate for principal rooms with real service/fixing value.

### W3 — genuine timber panelling

Use where panelling is architecturally wanted anyway.

### W4 — high-service wall

Deeper special case for bathrooms/kitchens/utility rooms.

## Kill condition

Reject W2 as a general system if the prototype:

- sounds hollow;
- looks like office fit-out;
- needs too many proprietary clips;
- is materially thicker/costlier without useful access;
- cannot match plaster visually/tactilely where calm wall fields are desired.

## Key principle retained

> **The lining is not necessarily the wall.**

# 4. Finish-Agnostic Floor Platform

## Current conclusion

This candidate has the strongest direct product-category precedent.

Dense removable calcium-sulphate access floors already prove:

- load capacity;
- individual exchange;
- stone/ceramic finishes;
- parquet finishes;
- high dimensional precision;
- acoustic/fire engineering.

The reference-house problem is domestic adaptation.

## Preferred architecture

```text
finish-specific visible layer
             │
finish-specific carrier
             │
COMMON PLATFORM INTERFACE
             │
dense removable mineral platform
             │
resilient / locating support
             │
shallow support lattice
             │
service / acoustic zone
             │
primary structure
```

## Serious comparator

A **local access band** or corridor/perimeter service strip may prove better than full-room removability.

That option should be tested honestly rather than treated as a retreat.

## Kill condition

Abandon full-room removable platforming if:

- normal footfall reveals “raised floor” acoustically;
- rattle/rock develops after cycling;
- visible module geometry dominates the room;
- the void creates disproportionate fire/acoustic complexity;
- local access bands achieve nearly all the serviceability value.

## Key principle retained

> **Standardise the interface, not the finish.**

# Cross-pattern rules now established

## 1. Conventional construction is the baseline

Every prototype is compared with the best conventional equivalent:

- plaster wall;
- conventional floor;
- certified hanger.

Novelty must earn its place.

## 2. Boundary independence

The removable layer should not casually become responsible for every critical performance.

Prefer slow, continuous boundaries behind fast architectural layers.

## 3. Reversibility is graded

Use three useful states:

- **inspectable**
- **repairable**
- **fully replaceable**

Do not call something replaceable when only its cover can be removed.

## 4. Access frequency is graded

Not every removable panel needs instant access.

Classify:

- routine access;
- occasional access;
- refurbishment-only removability.

## 5. Tactile quality is an acceptance criterion

A panel/floor system can pass calculations and still fail the house.

Prototype acceptance must include:

- sound;
- touch;
- stiffness;
- weight/solidity;
- joint quality;
- visual calm.

## 6. Proprietary mechanisms are suspect

The preferred pattern is:

**ordinary hidden hardware + architecturally specific visible piece**

not a custom mechanism that cannot be remade.

# Next decision sequence

The physical systems now need to be developed in this order:

## A. Working floor family — resolved for coordination

Use **engineered I-joists as the working reference-house baseline** for the next drawings.

This is not a final engineering lock. Metal-web joists remain a comparator when actual spans, vibration, depth and cost are known. The baseline exists so the floor edge can stop being abstract.

See: `docs/research/primary-floor-structure-baseline.md`.

## B. Draw one complete vertical bay

A single section should coordinate:

- masonry wall;
- floor structure;
- joist bearing/restraint;
- ceiling;
- backplane;
- wall panel;
- floor platform;
- service zone;
- cornice;
- skirting;
- fire/acoustic closure.

This drawing will expose conflicts much faster than four separate pattern sketches.

## C. Prototype the wall bay and floor bay

The wall/floor systems are now sufficiently grounded to justify 1:1 material testing.

## D. Only then select reference-house patterns

Candidate patterns should remain outside the Core Catalogue until those prototypes and calculations have happened.
