# Current-house theoretical setting

`node --import tsx publication/specimens/plt18/prepare.ts` prepares two source-owned setting readings. Build `b5`, `a4` and `a2` with `PLT18_FORMAT` and the local Vivliostyle config, then run `node --import tsx publication/specimens/plt18/validate.ts`.

B5/A4 are exactly 1:200; A2 is exactly 1:100. This retains the documented theoretical width and the current 3.5 m courtyard. It does not reopen RSI or select a real plot, equipment method, drainage solution or physical print verdict.
