# Joined section exemplar

Five sheets: principal section, roof, roof collection, front consequence and
courtyard consequence. B5/A4 1:100; A2 1:50. Run prepare.ts, build using
PLT09_FORMAT and vivliostyle.config.js, then validate.ts. No fit scaling.

Owner: docs/publication/architectural-plate-joined-section.md.

sizes remain nominal/unresolved; no physical acceptance is inferred.
