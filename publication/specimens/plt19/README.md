# Current sectional synthesis

Prepare with `node --import tsx publication/specimens/plt19/prepare.ts`. Build `b5`, `a4`, `a2` and `facing` with `PLT19_FORMAT` and this specimen's Vivliostyle config; validate with `node --import tsx publication/specimens/plt19/validate.ts`.

The B5/A4 lead-in ensures the spread starts on a verso when printed duplex. The facing PDF is a viewing aid, not printer imposition. All views are explicitly NTS, with fixed paper factors and unchanged physical tokens. Rendered and actual physical review are separate requirements. The owning [synthesis record](../../../docs/publication/architectural-plate-current-synthesis.md) records source, omissions and proof limits.
