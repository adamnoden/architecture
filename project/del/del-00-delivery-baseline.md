### Readiness vocabulary

- **BRIEFABLE:** an existing outcome/proof obligation can be carried into briefing, conditional on project selection. This never means technically passed or ready for construction.
- **DESIGN / PROFESSIONAL:** closure requires coordinated project information and competent discipline evidence.
- **PHYSICAL:** an applicable first article, installed demonstration or physical test must supply evidence.
- **SITE:** actual site, rights, target applicability or logistics must be supplied by the commission/DPL owner.
- **HELD:** not selected or not earned; no standing task is created.

Flags combine. Every admitted N requirement is BRIEFABLE at the obligation level; none has project acceptance evidence in this baseline. Unknowns remain open rather than receiving provisional passes.
