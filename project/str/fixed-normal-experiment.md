# Fixed normal-rule development experiment

This isolates vertical plate interpolation from the normal support rule and
clear-core gravity allocation, using the existing native builder and solver.
It is an exploratory numerical comparison, outside ordinary native admission.

The500 control captures its actual literal-q4 fibres and physical lower work
maps before serial body installation. Both models use the same25 beam stations
and in-plane500 mesh. The250 comparison retains that exact ledger and body
inventory, verifies geometric union equivalence, and derives only its current
upper Q4 traces. Direct nodal body-G ledgers must match before interpretation.
The archived geometry prototype is not used as an executed native response.

Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B
project/str/studies/fixed_normal_experiment.py --pitch 500 --out DIR`, then250
with `--ledger DIR/fixed-normal-ledger.json`. Completed full responses and
receipts bind the native58 plus transforming methods and numerical runtime.
Their distinct schemas deliberately reject ordinary current-floor admission.

Four analytical/adverse controls cover work/first moments, missing material,
actual ground coordinates, reversible failure and geometric body equivalence.
No coupled result is claimed by this preparation. Compare actual52 heads and
the existing exact signed cuts under the unchanged0.1kN/kNm and5% screens.
Finite joints, physical materials, anchors, signed loading and house selection
remain separate duties. The ordinary failed refinement controls are retained.
