## Loads, method and limits

The method is a linear3D Euler–Bernoulli RHS frame with consistent uniform selfweight and physical rigid member-end offsets. Axial, biaxial bending, Bredt torsion, actual web shear areas and a conservative cantilever Euler magnification enter the member comparison. Interior stations have an explicit quadratic uniform-load interpolation allowance; only checking end forces would miss a gravity maximum. Closed-form tip-force and uniform-gravity cantilevers verify the element, and an eccentric-root control verifies all transferred lever moments. Diagonally scaled Cholesky solves and residual checks handle the very short bracket spacers without relaxing equilibrium tolerances.

Wall-pad translations and rotationsX/Z are restrained; normal-axis rotationY is released, so pad friction is not silently used to resist that moment. This is an authored limiting joint model. Actual pad/anchor/concrete rotational stiffness remains unqualified. Each returned wall wrench retains all six components.
