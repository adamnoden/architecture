# Workstream code migration closeout

**Scope:** publication stage namespace plus physical/professional validation workstream identities.

## Result

- `PUB` is the canonical publication workstream identity; live release stages are `PUB-00` … `PUB-06`.
- Historical `PR-00` … `PR-06` identifiers remain aliases only; frozen `pr00*` / `pr01*` evidence names are preserved.
- `PHY` is the canonical physical-validation workstream identity; live packets are `PHY-01` … `PHY-04`.
- Historical `P01` … `P04` identifiers and derived evidence identifiers remain provenance aliases.
- `EPR` is the canonical external-professional-review workstream identity.
- `RH-11` remains the Reference House review gate and is executed through EPR rather than renamed.

This migration changes naming/control topology only. It does not raise maturity, manufacture authority, validation status, evidence quality or architectural scope.
