# OAS representative-detail completion

The final execution audit found that OAS-03's explicitly bounded architectural
topology did not supply the representative dimensioned interface set required
by the original OAS programme. A renewal diagram is not that set.

OAS-03 remains a valid historical topology selection at its recorded scope;
it does not discharge the missing detail obligation. The canonical OAS-DETAIL
node now owns it and TRIAD-GATE explicitly depends on that node.

Required output: source-owned nominal architectural studies of a current-wall
window head, jamb and sill, an external threshold and an internal-door/trim
interface, with dimensioned assumptions, actual drawing scale and replacement/
water/boundary consequences. These are representative architecture for BCR/
prototype scoping, not fabricated product sections or engineering certification.

No existing held detail is relabelled as proven. New geometry must acquire
explicit local design authority, retain the current source datums where used,
and distinguish a study assumption from an installation tolerance or order size.
The result must identify unresolved whole-house/product/site consequences.

This node makes the missing original obligation visible rather than silently
weakening the triad gate. The final selected-house gate may reject a nominal
detail where actual product or technical evidence defeats it.
