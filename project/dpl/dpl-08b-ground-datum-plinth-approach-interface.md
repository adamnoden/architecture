**Issue:** [#376 — DPL-08B — ground, datum, plinth and accessible-approach interface](https://github.com/adamnoden/architecture/issues/376)  
**Programme:** [#299 — DPL — deployment, jurisdiction and real-site integration programme](https://github.com/adamnoden/architecture/issues/299)  
**Authorised by:** [#373 — DPL-B1 — Wave B1 integration and next-wave readiness gate](https://github.com/adamnoden/architecture/issues/373)  
**Baseline `main`:** `b50ff9008319051a85dbdda2a4e53369ac433b43`  
**Parent interface register:** [DPL-08A](dpl-08a-site-interface-authority-register.md)  
**Reference Site:** `DPL-RS-01`  
**Status:** conditional site-interface contract; **not** foundation, retaining, drainage, threshold or access construction design

## Question

> **What must be true at the land ↔ building junction for ground support, absolute datum, plinth/wall-base performance and the principal accessible approach, without pretending that site facts or competent technical design already exist?**

DPL-08B takes `SI-P01 — Ground / Foundation Support` and `SI-P02 — Datum / Plinth / Accessible Approach` from the DPL-08A authority register into one bounded substantive interface contract.

It does not select foundations, draw a construction-ready plinth, prove an accessible route or make the Reference Site compliant.

---

# 1. Result

The ground interface is **not one plinth detail**.

It is a coordinated junction between five duties that remain separately owned:

1. **`GI-D01 — SUPPORT`** — transfer the controlled superstructure/load-path proposition into evidenced ground through competent engineering;
2. **`GI-D02 — DATUM`** — select the building's absolute site elevation while preserving the protected internal relative-level architecture;
3. **`GI-D03 — WEATHER / MOISTURE`** — preserve wall-base and threshold air/thermal/moisture/weather duties without assuming one perimeter drainage detail;
4. **`GI-D04 — ACCESS / MOVEMENT`** — provide the principal external approach and threshold sequence required by the applicable target and project intent without making a second-class route;
5. **`GI-D05 — MAINTENANCE TERRITORY`** — preserve the ground/support/inspection territory needed for future ordinary façade, roof-edge, plant and wall-base maintenance.

These duties may share physical geometry only where technical evidence shows that doing so is compatible.

The governing rule is:

> **One piece of ground may perform several duties; no duty is discharged merely because another duty happens to occupy the same strip.**

Therefore none of the following is a valid DPL-08B shortcut:

```text
raised plinth = accessible threshold solved
level threshold = weathering solved
perimeter gravel = drainage solved
hardstanding = maintenance solved
foundation selected = ground risk solved
```

The correct model is:

```text
CONTROLLED HOUSE HANDOFFS
      +
EVIDENCED SITE CLAIMS
      +
APPLICABLE EXTERNAL OBLIGATIONS
      ↓
FIVE COUPLED INTERFACE DUTIES
      ↓
CONDITIONAL RESPONSE FAMILY
      ↓
SPECIALIST / TARGET PROOF
      ↓
CONFORMANCE TEST
```

At this packet the response remains conditional. Construction geometry follows later evidence and competent design.

# 2. Authority recovered

## 2.1 DPL-02 — conformance boundary

DPL-02 deliberately leaves foundation/ground support and absolute datum/external-level transition as site-interface freedoms **provided the protected Reference House remains intact**.

It does not authorise:

- changing the 12.0 × 10.8 m gross shell merely to fit a plot;
- changing the protected courtyard or plan topology;
- creating split internal levels as a casual site response;
- moving the principal entrance/order for convenience;
- replacing the protected load-path proposition with a materially different architectural structural system without an explicit Reference House rewind.

Foundation engineering details remain implementation freedom only while they do not create architectural consequences above.

## 2.2 DPL-07 — Reference Site

`DPL-RS-01` gives this contract one synthetic integration fixture:

- 17.4 × 30.0 m parcel;
- street to geographic north;
- Reference House rotated rigidly 180°;
- 5.2 m front approach field;
- broad existing fall of 240 mm over 30 m (~1:125) from street/front to rear;
- provisional RH ground FFL at site `Z = +0.100 m`;
- 3.0 m service-side and 2.4 m principal-side gross fields;
- one synthetic mature rear tree;
- ordinary neighbouring masses;
- ground profile, bearing parameters, groundwater, contamination and ground gas explicitly `UNKNOWN`.

The fixture is enough to exercise the contract. It is not evidence that the resulting interface is technically adequate.

## 2.3 DPL-08A — site-interface packages

DPL-08A already establishes:

- `SI-P01` owns the local response between the protected superstructure/load-path handoff and actual evidenced ground;
- `SI-P02` owns the local response between protected internal relative levels and actual external levels/approach conditions;
- neither package owns site facts, external requirements or specialist adequacy;
- difficult ground is not itself incompatibility if a competent conformance-preserving response exists;
- a site-interface solution that crosses protected architectural order must stop and trigger a Reference House rewind or site rejection.

## 2.4 Reference House — external maintenance

The controlled External Access & Maintenance Plan explicitly rejects one universal `perimeter dry zone` solution.

It requires wall-base drying, drainage, inspection and maintenance-support territory to be coordinated **as distinct functions** because they can conflict.

Drainage must come from actual levels, soils, foundations and discharge routes. Gravel/French-drain logic is not an architectural default.

## 2.5 Reference House — envelope

RH-10 retains a conventional masonry cavity-wall family as the architectural/pre-building-physics baseline but reserves exact thermal, moisture and junction performance for later technical design.

The slow envelope must remain complete when replaceable trim is removed.

That requirement matters at the ground junction: the site interface must not make a removable threshold trim, landscape edge or decorative plinth the sole air/water/moisture boundary.

## 2.6 Human factors / inclusive-design review boundary

The current Reference House intends:

- a substantially level principal entrance and internal ground-floor route;
- one principal domestic route rather than a separate second-class accessible entrance;
- low-friction thresholds where credible.

The RH-11 inclusive-design brief expressly keeps real-site approach levels, gradients, boundary/set-down conditions, finished threshold geometry and product facts open pending site/technical evidence.

DPL-08B therefore protects the **duty and architectural reservation**, not an invented numeric slope or threshold construction.

## 2.7 DRW-11 — construction-detail restraint

DRW-11D admits **zero construction-style details** at current authority.

For the external threshold it records:

- substantially flush architectural intent: selected;
- level-access geometry: open technical design;
- drainage/weathering: open technical design;
- doorset relation: open technical design;
- thermal/air/water closure: open technical design.

DPL-08B does not overturn that decision.

### Threshold identifier hygiene

Earlier DPL-08A prose uses `TH-02` for the principal entrance threshold while DRW-11D uses `TH-01` for an external threshold. The canonical pattern occurrence register names the **Designed Threshold** occurrence functionally but does not freeze either identifier.

DPL-08B therefore uses the neutral term **principal external threshold occurrence**. The identifier discrepancy is a nomenclature-cleanup item, not architectural authority and not a reason to block this packet.

# 4. `GI-D01 — SUPPORT`

## Building-side handoff

The Reference House supplies:

- controlled outer/courtyard permanent support geography;
- a selected architectural structural concept based on permanent masonry boundaries doing useful loadbearing work;
- protected gross shell/courtyard geometry;
- protected internal relative levels and sectional hierarchy;
- short-span upper-floor/roof logic coordinated around those permanent boundaries;
- later-engineered actions/reactions as inputs to foundation design.

It does **not** supply:

- footing type;
- foundation width/depth;
- pile/raft/strip selection;
- reinforcement;
- bearing capacity;
- settlement prediction;
- heave/shrinkage solution;
- ground improvement;
- retaining design.

## Required site/evidence inputs

Where material, the support duty consumes:

- authoritative topography;
- intrusive/geotechnical ground evidence;
- groundwater evidence;
- contamination / ground-gas / aggressive-ground evidence;
- trees / root-related evidence;
- adjacent structures/foundation evidence;
- buried sewer/utility apparatus;
- slope/stability evidence;
- working/legal boundary constraints;
- construction access / temporary-works constraints;
- competent structural actions/reactions from the building design.

No missing item is defaulted optimistically.

## Conditional response class

The permitted response is:

> **a competent engineered ground/foundation/support system that transfers the protected Reference House load-path proposition into the evidenced site without creating material above-ground architectural consequences.**

That definition intentionally admits more than one engineering family.

DPL-08B does not rank shallow foundations, rafts, piles, ground improvement or other families.

## Specialist boundary

Competent structural/geotechnical design owns:

- bearing/settlement;
- depth and geometry;
- reinforcement;
- heave/shrinkage/root effects;
- retaining;
- ground improvement;
- temporary works;
- adjacent-foundation interactions;
- structural adequacy and robustness.

## Rewind / incompatibility triggers

A local support response leaves DPL-02 freedom if it requires, for example:

- material change to outer/courtyard support geography;
- intrusive permanent columns or major transfer structure in protected rooms;
- materially raised/split internal floors;
- retaining structures that become a new dominant architectural composition;
- moving protected rooms/service geography to avoid ground/services;
- another above-ground architectural consequence outside current implementation freedom.

A hard site constraint may ultimately make the plot incompatible. The engineering system being unusual or expensive does not by itself prove incompatibility.

# 5. `GI-D02 — DATUM`

## Building-side handoff

The house supplies protected **relative** levels:

- ground FFL `±0` in house coordinates;
- one-level entrance-storey topology;
- first FFL +3300 mm and the controlled sectional hierarchy above;
- principal entrance position/order;
- substantially level internal ground-floor circulation.

The house does not supply one universal absolute site elevation.

## Required site/evidence inputs

- topographical survey tied to a stable datum;
- street/footway/drive/approach connection levels;
- boundary/highway relation;
- neighbour and garden level conditions where consequential;
- groundwater/flood/surface-water facts where they affect datum selection;
- retaining constraints;
- trees and ground constraints affecting grading;
- service/sewer levels where they materially constrain the site response;
- target-selected approach/access obligations.

## Conditional response class

The response may choose:

- absolute house FFL;
- local grading;
- path/terrace levels;
- bounded retaining;
- local wall-base ground separation;

provided it preserves protected internal relative levels and architectural order.

The governing preference is not “lowest possible house” or “highest possible plinth”. It is a coordinated site datum that allows the other four duties to be resolved without hidden contradiction.

## Rewind triggers

- internal split levels become necessary;
- protected visible sectional hierarchy must materially change;
- principal entrance must move or become a secondary route;
- grading/retaining becomes a major architectural intervention outside current site-interface freedom;
- datum selection destroys another protected service/water/maintenance relationship with no admissible alternative.

# 6. `GI-D03 — WEATHER / MOISTURE`

## Building-side handoff

The Reference House requires:

- a durable slow envelope whose air/thermal/moisture duties do not depend on removable trim;
- inspectable/manageable wall-base conditions;
- a principal external threshold that can remain substantially level without hiding water risk;
- no brittle/fast-changing component becoming the sole permanent weather boundary;
- visible/maintainable water behaviour consistent with wider Ovid's House doctrine.

DPL-08B does not freeze a DPC height, cavity tray, channel drain, membrane family, waterproofing system or paving build-up.

## Required site/evidence inputs

- finished and existing external levels;
- rainfall/surface-water flow paths relevant to the site design;
- local drainage/outfall evidence;
- ground/groundwater condition;
- soil/permeability evidence where infiltration is proposed;
- threshold approach geometry;
- retaining/below-ground conditions;
- wall/foundation technical design;
- doorset and threshold product geometry at the appropriate design stage.

## Separate duties at the wall base

At minimum keep distinct:

1. **bulk surface-water control** — keep site runoff from being driven toward vulnerable fabric;
2. **splashback / wetting management** — limit recurrent wetting at exposed wall bases;
3. **drying potential** — avoid trapping moisture through decorative or landscape treatments;
4. **inspection access** — make consequential wall-base condition observable/reachable;
5. **air/thermal/moisture continuity** — preserve the permanent envelope boundary;
6. **threshold weathering** — resolve low-friction movement without assuming zero water-management depth.

One detail may satisfy several of these later. DPL-08B does not assume it does.

## Forbidden shortcut

There is no canonical:

```text
continuous gravel trench = perimeter dry zone = drainage = maintenance strip
```

A gravel margin, drained channel, paved apron, planted strip or other response must earn its use from actual technical/site duties.

## Specialist boundary

Building physics / envelope / drainage design owns the final closure, including product-specific weathering and moisture risk.

## Rewind triggers

- a substantially level principal threshold proves impossible without a material architectural step or entrance redesign under the applicable target;
- the wall-base strategy requires material protected-envelope/order changes;
- site water can only be made safe by altering protected internal levels or moving the principal entrance;
- a technically credible response cannot coexist with the support/access/maintenance duties after admissible alternatives are exhausted.

# 7. `GI-D04 — ACCESS / MOVEMENT`

## Architectural duty

The current house protects:

- one principal domestic arrival, not a hidden alternative accessible entrance;
- a substantially level principal entrance/ground-floor sequence;
- a low-friction external threshold ambition;
- protected internal ground-floor continuity;
- sufficient front site-interface territory to resolve real approach conditions where the site permits it.

DPL-08B deliberately does **not** invent numeric approach gradients, landing dimensions, crossfalls, door clearances or threshold tolerances ahead of the applicable DPL-09 access target and competent technical/product design.

## Required site/evidence inputs

- exact arrival/connection point(s) from highway/site entrance;
- authoritative levels along candidate approach routes;
- route width/obstruction facts;
- boundary/gate/parking/refuse conflicts;
- drainage and crossfall constraints;
- door/threshold product geometry later;
- the exact applicable accessibility obligation selected by planning/building-control target composition;
- any actual user brief stronger than the generic Reference House baseline.

## Conditional response class

An admissible response may use:

- ordinary grading;
- a gently sloped principal path;
- local landings/terraces;
- bounded retaining;
- integrated drainage/weathering;

provided the route remains recognisably the principal entrance sequence and does not consume protected maintenance/service geography without a replacement route.

## Result discipline

Before the exact target and real levels are known, the correct result is generally:

```text
ACCESS DUTY:        PRESENT
SPATIAL RESERVATION: PRESENT / testable
TECHNICAL ADEQUACY: UNRESOLVED
```

not `PASS`.

## Rewind / incompatibility trigger

If the applicable target requires a route that cannot be achieved through any credible conformance-preserving site response, the deployment case does not gain permission to move the principal entrance or introduce arbitrary internal level changes.

The result is:

1. test remaining admitted site responses;
2. if exhausted, expose the conflict;
3. choose explicit Reference House rewind **or** reject the site for the current house.

# 8. `GI-D05 — MAINTENANCE TERRITORY`

## Architectural duty

The house requires credible ordinary future access for foreseeable façade, roof-edge, rainwater, opening, plant and wall-base work.

At ground level this creates a duty for useful temporary support / working / inspection territory at selected positions.

It does not create a universal hard-paved collar around the house.

## Required site/evidence inputs

- boundaries and neighbour/highway relations;
- final ground levels;
- temporary bearing/support conditions;
- drains/chambers beneath support areas;
- permanent planting / mature tree envelopes;
- external plant;
- walls/fences/gates;
- rights/consents where maintenance depends on neighbour/highway land;
- selected task/equipment assumptions at later design stages.

## Conditional response class

The response may use combinations of:

- hard landscape;
- structurally suitable temporary bearing positions;
- removable landscape;
- ordinary garden/side passage territory;
- task-specific neighbour/highway dependency where justified and recorded.

The ground may remain domestic and planted in ordinary use. The requirement is that foreseeable maintenance not be made specialist by accident.

## Conflict rule

If drainage, planting, an access ramp, external plant or another site feature occupies Category-A maintenance territory, the project must prove that the combined geometry still works or provide an equivalent credible route.

A maintenance route is not automatically superior to accessibility, drainage or landscape. The duties must be coordinated without silently deleting one another.

# 9. Cross-duty compatibility matrix

DPL-08B freezes the following interactions for later technical design.

| Pair | Required coordination | Failure to avoid |
|---|---|---|
| support ↔ datum | foundation/retaining response must support selected absolute FFL without changing protected internal section | engineering solution forces split-level architecture |
| datum ↔ weather/moisture | external levels must manage water while preserving intended entrance relation | level approach directs water into envelope |
| datum ↔ access | absolute FFL and grading must leave a credible principal route under applicable target | datum chosen first makes access impossible |
| datum ↔ maintenance | grading/retaining should not consume essential ordinary support positions | beautiful plinth creates permanent access trap |
| support ↔ maintenance | temporary access loads/chambers/ground response need later coordination | scaffold/tower bears over unsuitable ground or services |
| weather/moisture ↔ maintenance | wall base must remain inspectable/repairable | decorative/drainage assembly hides slow failure |
| weather/moisture ↔ access | low-friction threshold must retain robust weathering/drainage | wheelability solved by water ingress |
| access ↔ maintenance | principal route and temporary work territory may overlap only if both remain credible | accessibility path permanently consumes sole service/maintenance route |

The matrix is a coordination contract, not a pass/fail calculation.

# 10. Evidence ladder by assurance profile

## `SCREENING`

Useful minimum evidence:

- approximate but sourced parcel/house relation;
- credible street/approach relation;
- available public level/topographic cues where any exist;
- obvious severe slope/tree/boundary/retaining constraints;
- explicit ground/geotechnical unknowns.

Permitted claim:

> no obvious site-interface blocker observed at the available evidence resolution, **or** named blocker/unknown requires escalation.

Not permitted:

> foundations/access/plinth comply.

## `FEASIBILITY`

Normally require substantially better:

- reliable topography;
- working boundary/context geometry;
- initial geotechnical/site-risk evidence proportionate to identified risk;
- approach/retaining/drainage concept;
- major tree/adjacent-structure constraints;
- applicable target route known sufficiently to test principal access.

## `PLANNING_CASE`

Planning evidence may make approach, retaining, trees, visible plinth/landscape, flood/drainage and context duties due even where final structural design is later.

Planning acceptability remains separate from building-control or engineering adequacy.

## `TECHNICAL_DESIGN`

Require competent coordinated design sufficient to close:

- foundation/support response;
- final datum/grading/retaining;
- threshold/wall-base air/water/moisture continuity;
- accessible route geometry under the applicable target;
- maintenance bearing/support conflicts;
- product/assembly interfaces.

DPL-08B does not itself provide that design.

# 13. Relationship with DPL-09B

DPL-09B owns the first England structure/ground/moisture/material target slice.

The boundary is:

```text
DPL-09B
  owns applicable normative obligation + method/evidence class

DPL-08B
  owns the site-conditioned architectural/technical interface response boundary
```

Examples:

- DPL-09B may establish that structural adequacy or resistance to ground moisture is an applicable obligation;
- DPL-08B identifies which site evidence and local interface response must eventually satisfy that obligation;
- competent engineering/building-physics design supplies adequacy where the compiler cannot prove it natively.

DPL-09B must not select a foundation or wall-base assembly merely because DPL-08B names the duty.

# 15. Rewind hierarchy

When a site condition conflicts with the interface, use this order:

1. **improve evidence** — do not redesign around an uncertain fact;
2. **test an admitted site-interface response**;
3. **test another competent conformance-preserving response** where one genuinely exists;
4. **expose unresolved professional/technical determination** where adequacy is not compiler-native;
5. if every credible route crosses DPL-02 protected order, classify the deployment conflict explicitly;
6. then choose either:
   - upstream Reference House rewind through the owning architectural gates; or
   - reject the site for the current Reference House revision.

Never patch the site manifest, target or drawing merely to keep the candidate green.

# 18. Closeout

DPL-08B's result is deliberately architectural rather than product-specific:

> **The ground/plinth interface is a coordinated contract between five separately owned duties—support, datum, weather/moisture, access/movement and maintenance territory. Site evidence and applicable targets select the technical problem; competent design resolves it; DPL-02 determines whether the result is still the Reference House.**

No universal foundation, plinth, ramp, threshold or perimeter-drainage detail is selected.

That restraint is the packet's principal result, not an absence of design.
