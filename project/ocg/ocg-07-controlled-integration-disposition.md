## Consequence-envelope method

The intervention consequence envelope and complete intervention sequence remain in `project/ocg/` as **internal cross-cutting audit machinery**.

They do not become:

- a new governing principle;
- a pattern family;
- a Reference House design layer;
- a delivery specification;
- a publication taxonomy;
- a compiler object by virtue of integration.

This is deliberate. The method tests whether existing architecture has bounded change; it does not need to own the architecture that does so.

# 3. OCG-07B — architectural rewind decision

**No architectural rewind is earned.**

OCG-05 tested CI-01…CI-13 against current controlled RH authority and found:

- zero `DEFECT_CANDIDATE`s;
- no contradiction requiring GP/pattern/RH topology change;
- no stale downstream artefact;
- deliberate accepted-disruption boundaries at CI-10 and CI-13.

Accordingly OCG-07 does **not** authorise:

- additional access panels;
- larger service zones;
- a house-wide access floor;
- replaceable lining as a house-wide system;
- universal manifolds or extra isolation granularity;
- duplicate wet-service routes or second soil stack;
- spare structural flexibility;
- duplicate kitchens/bathrooms for work continuity;
- new RH geometry, service topology or drawing changes.

A later technical proof can still trigger its **existing** owning rewind condition. OCG creates no new one merely because proof remains outstanding.

# 4. OCG-07C — delivery / contractor-method boundary

The following remain principally temporary/project delivery matters:

- furniture/floor/finish protection;
- temporary dust partitions and local containment;
- local extraction and ventilation during works;
- work sequencing and work-hour management;
- tool choice and cutting/fabrication method;
- temporary water/power/cooking/sanitary provision where required;
- daily housekeeping;
- material and waste packaging/handling;
- commissioning procedure;
- final construction cleaning and hygienic return-to-use.

Permanent architecture may make these easier or harder. That causal effect is auditable. But the measures themselves do not become permanent architectural doctrine.

**No new delivery requirement is added by OCG-07.** Existing delivery authority remains the correct owner when a real project turns these controls into contract requirements or method statements.

# 7. Rejected integration theatre

The following would create visible activity while making the project worse:

1. adding `Change should be bounded` as a twelfth constitutional provision;
2. duplicating GP5 as an OCG maintenance-geography pattern;
3. adding access infrastructure merely to demonstrate that OCG changed the house;
4. promoting held RH candidates because they help one intervention;
5. creating OCG-specific contractor requirements already owned by normal delivery;
6. opening prototype programmes for assemblies the architecture has not selected;
7. changing drawings or publication language before publication re-entry decides whether the reader needs anything.

All are rejected.
