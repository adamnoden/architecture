# 1. Decision

The typed graph can now be reduced to a decision matrix without reopening discovery.

Across the fifteen canonical claims, three broad conditions recur:

1. **Inherited proposition, already honestly framed.**  
   The project is using established territory and mostly says so. These claims need at most source precision or a local note.

2. **Inherited proposition, but the current source story is incomplete.**  
   The Ovid formulation may remain strong, but a closer antecedent or converging tradition should probably be visible somewhere to prevent accidental priority implication.

3. **Inherited proposition whose current rhetorical transition is materially misleading.**  
   This is rarer. The strongest present example is C02: the manuscript moves from Duffy/Brand's layer lineage to `the important condition is coupling`, even though Brand already explicitly owns destructive embedding / inadequate slippage between differently paced layers.

The matrix therefore does **not** produce fifteen equal attribution problems.

The likely ILA-04 decision load is concentrated around:

- **C02 — coupling / Brand**;
- **C04 — committed adaptable form / Van Eyck + Hertzberger + Habraken precision**;
- **C12 — Repose / Bidlake-Wainwright + compound domestic lineage**;
- **C15 — Alexander / pattern and generative-sequence authority**;
- secondarily **C10 — open systems / interoperability** and **C14 — Kahn / service order**.

The rest appear capable of being resolved through T0–T2 treatment or restrained precision, subject to ILA-04.

# 21. Matrix-wide Ovid delta

The graph-level synthesis survives the claim-by-claim matrix.

The strongest defensible Ovid contribution is not one isolated historical innovation. It is the repeated use of the following governance pattern across a detached domestic house:

1. **proportionality** — future provision must earn present burden;
2. **physical dependency** — replacement is judged by what must actually be destroyed / crossed / reinstated;
3. **maintenance geography** — future work has approach, work position, handling and withdrawal geometry;
4. **failure geography** — credible abnormal states have visible/local/recoverable paths;
5. **weak stewardship** — the design assumes records, suppliers and institutional memory can decay;
6. **architectural commitment** — serviceability does not require a neutral shell or continuous technical display;
7. **workmanship robustness** — real tolerances and ordinary competent construction are first-class constraints;
8. **typed authority** — evidence, pattern maturity, project occurrence, semantic model, compiler check and publication claim stay distinct;
9. **rewind authority** — downstream evidence can invalidate an upstream architectural decision rather than being forced to fit it.

Primary delta classification:

`SYNTHESISES + OPERATIONALISES + NARROWS + TRANSFERS_DOMAIN`, with claim-specific mixtures.
